# PS-TM100 – Validierung der Prüfsoftware

**Projekt:** PS-TM100 · **Arbeitspaket:** AP-3 · Demo-Inhalt

Die Prüfsoftware gilt als validiert, wenn das Gutteil (Goldenes Muster) besteht und jedes
Fehlermuster erkannt wird.

| Muster | Erwartung | Ergebnis |
|---|---|---|
| Gutteil GM-01 | bestanden | offen |
| Fehlermuster FM-01 Sensor verstimmt (+0,8 K) | durchgefallen in Schritt 2 | offen |
| Fehlermuster FM-02 Serviceschnittstelle offen | durchgefallen in Schritt 3 | offen |
